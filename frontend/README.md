# Frontend

React + TypeScript application built with Vite.

Contains two views:

- **Simulated Banking Application** — where customers initiate transactions.
- **Fraud Analyst Dashboard** — where analysts review flagged transactions, risk scores, and explanations.

## Planned Libraries

- Tailwind CSS + shadcn/ui for UI components
- React Router for navigation
- Axios for API communication
- React Hook Form + Zod for form validation
- Recharts for data visualisation

Not yet implemented. Foundation placeholder only.
